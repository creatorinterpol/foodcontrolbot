# 🍽️ Food Control Bot

Telegram-бот для управления меню школьной столовой.

## 🚀 Развёртывание на Amvera

### 1. После пуша на GitHub

Amvera автоматически пересоберёт контейнер. Если нет — пересоберись вручную:
- Зайди в Amvera → Приложение → Перестроить

### 2. Требуемые переменные окружения

В Amvera → Приложение → Переменные окружения добавь:

```
TELEGRAM_BOT_TOKEN=твой_токен_бота
DATABASE_URL=postgresql://пользователь:пароль@host:5432/database
TZ=Europe/Moscow
```

### 3. PDF меню

**ВАЖНО:** PDF файл не загружается в Git (он в `.gitignore`).

**Вариант 1 - Через Amvera UI:**
- Зайди в Amvera → Файлы → Загрузи `Меню 01_09_2026.pdf` в `/app/`

**Вариант 2 - Через SFTP:**
```bash
sftp user@host
put "Меню 01_09_2026.pdf" /app/
```

**Вариант 3 - Если часто обновляется:**
Создай отдельное хранилище (S3/объектное хранилище) и измени путь в `menu_pdf.py`:
```python
MENU_PDF_PATH = "/mnt/storage/меню.pdf"  # или s3://bucket/меню.pdf
```

### 4. Проверка логов

```bash
amvera logs tail app
```

Должно быть:
```
Папка для картинок меню подготовлена
Запуск автоматической отправки меню...
```

### 5. Тестирование

Отправь боту:
- `/start` - авторизация
- `/menu` - текущее меню
- `/status` - статус

## 📋 Что изменилось в этом обновлении

### ✅ Исправлена логика недель
- **Было:** 52 недели (ISO номер)
- **Стало:** 2 недели в цикле (повторяется)
- Отсчёт от 1 сентября 2026 года

### ✅ Добавлена отправка фото из PDF
- Бот извлекает нужную страницу из PDF
- Конвертирует в PNG через PyMuPDF
- Автоматически отправляет в 14:00 МСК

### ✅ Приоритет источников
1. Фото из PDF (если доступен)
2. Загруженные через `/upload_menu`

## 📦 Новые зависимости

```
pypdf>=3.17.0      # Чтение PDF
PyMuPDF>=1.23.0    # Конвертация в изображения
```

## 🔧 Структура PDF

Предполагается, что PDF содержит 10 страниц:
- Страницы 0-4: Неделя 1 (ПН-ПТ)
- Страницы 5-9: Неделя 2 (ПН-ПТ)

## 📝 Примечания

- Выходные (СБ, ВС): Меню не отправляется
- Праздничные дни: Нужно настроить вручную в `config.py`
- Часовой пояс: МСК (Europe/Moscow)
